# 抽卡开发音效槽位

本目录只用于本地开发占位，不随正式版本分发。

前端会优先尝试读取下面这些文件名；文件不存在时会自动使用浏览器合成的轻量提示音：

- `case_unlock_01.wav`
- `csgo_ui_crate_item_scroll.wav`
- `csgo_ui_crate_open.wav`
- `case_awarded_0_common_01.wav`
- `case_reveal_rare_01.wav`
- `case_reveal_mythical_01.wav`
- `case_reveal_legendary_01.wav`

这些名称对应 CSGO 开箱音效的开发替换槽位。正式分发前，请删除临时原声并替换为自制或已获得授权的音效，同时更新资源清单与许可说明。
